# Smart-Hospital-Management-And-Resource-Allocation-system
A C++-based hospital management system designed to efficiently manage patients, doctors, hospital beds, emergency cases, and resource allocation. The system prioritizes critical patients, allocates suitable resources based on availability and urgency, and helps manage patient transfers when required.

Patient registration and management
Emergency and priority-based patient handling
Hospital bed allocation and tracking
Doctor allocation and management
Patient discharge and bed availability updates
Critical patient handling and hospital transfer logic
Real-time time-based management
Efficient resource allocation using data structures and algorithms
Menu-driven interface

Tech Stack
Language: C++
Concepts: Data Structures, Algorithms, OOP, Queues, Priority Queues, Graphs, File Handling, and CRUD Operations

Developed as a Problem-Based Learning (PBL) project to demonstrate the practical application of data structures and algorithms in healthcare resource management.
