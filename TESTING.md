# Testing Guide

## Build Instructions

1. Install a C++ compiler that supports C++17, such as g++.
2. Open a terminal in the project directory.
3. Compile the project using the repository's provided build instructions or batch file.
4. Run the compiled program.

## Manual Testing Checklist

- [ ] Verify that the application starts successfully.
- [ ] Check patient registration with valid input.
- [ ] Check how the application handles invalid menu choices.
- [ ] Verify patient search and display features, where available.
- [ ] Check bed allocation and availability features, where available.
- [ ] Verify discharge or transfer operations, where available.
- [ ] Confirm that invalid input does not cause unexpected behavior.

## Notes

Record the test inputs, expected results, and actual results when testing. Feature availability may vary by implementation.
